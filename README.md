## 🇺🇿 O'zbekcha

Sport zallari, jang san'ati maktablari va murabbiylar uchun ishlab chiqilgan avtomatlashtirilgan boshqaruv tizimi (SaaS CRM).

### ⚙️ Texnologiyalar (Tech Stack)
* **Backend:** Python 3, Django 6.1 (Custom User Model & Role-based Access)
* **Database:** Neon PostgreSQL (Cloud Serverless DB)
* **Deployment & Static:** Render, Gunicorn, WhiteNoise

### 🚀 Asosiy Imkoniyatlar
* Murabbiylar va sportchilar profilini alohida rollar asosida boshqarish
* Guruhlar va kurslar bo‘yicha moliyaviy to‘lovlar tarixi va nazorati
* Kunlik davomatni yagona cheklovlar (Unique Constraints) bilan xatosiz yuritish
* Tug‘ilgan sana asosida sportchi yoshini avtomatik hisoblash

## 🇷🇺 Русский

Автоматизированная система управления (SaaS CRM) для спортивных залов, школ единоборств и тренеров.

### ⚙️ Технологии (Tech Stack)
* **Backend:** Python 3, Django 6.1 (Custom User Model и ролевой доступ)
* **База данных:** Neon PostgreSQL (Облачная Serverless БД)
* **Деплой и статика:** Render, Gunicorn, WhiteNoise

### 🚀 Основные возможности
* Раздельное управление профилями тренеров и спортсменов на основе ролей
* Полный контроль и история финансовых платежей по группам и курсам
* Точный ежедневный учет посещаемости с защитой от дублирования (Unique Constraints)
* Автоматический расчет возраста спортсменов по дате рождения

## 🇬🇧 English

Automated management system (SaaS CRM) built for sports clubs, martial arts academies, and coaches.

### ⚙️ Tech Stack
* **Backend:** Python 3, Django 6.1 (Custom User Model & Role-Based Access Control)
* **Database:** Neon PostgreSQL (Cloud Serverless DB)
* **Deployment & Static:** Render, Gunicorn, WhiteNoise

### 🚀 Key Features
* Role-based profile management for coaches and athletes
* Financial payment tracking and history across training groups and courses
* Daily attendance tracking enforced with database-level Unique Constraints
* Dynamic athlete age calculation based on birth date

## 🇩🇪 Deutsch

Automatisiertes Verwaltungssystem (SaaS CRM) für Sportvereine, Kampfsportschulen und Trainer.

### ⚙️ Technologie-Stack (Tech Stack)
* **Backend:** Python 3, Django 6.1 (Custom User Model & rollenbasierte Zugriffskontrolle)
* **Datenbank:** Neon PostgreSQL (Cloud Serverless DB)
* **Deployment & Statische Dateien:** Render, Gunicorn, WhiteNoise

* Rollenbasierte Profilverwaltung für Trainer und Athleten
* Finanzielle Zahlungsverfolgung und Historie nach Trainingsgruppen und Kursen
* Tägliche Anwesenheitserfassung mit datenbankseitigen Unique Constraints
* Dynamische Altersberechnung der Athleten basierend auf dem Geburtsdatum
